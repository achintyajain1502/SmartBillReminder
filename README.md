# 📱 SmartBillReminder

*SmartBillReminder* is an Android application designed to help users manage their bills and receive timely reminders for upcoming payments. 🔔

---

## ✨ Features

* 🧾 Add and manage bills
* 💰 Store bill name and amount
* 📅 Set bill due dates
* 🔔 Set reminders for upcoming bills
* 📋 View upcoming bills
* ✏️ Edit existing bills
* 🗑️ Delete bills
* 🔔 Receive notification reminders
* 📱 Simple and user-friendly interface
* ⚡ Lightweight and easy to use

---

## 🛠️ Technologies Used

* 💻 **Language:** Kotlin
* 📱 **Platform:** Android
* 🧑‍💻 **IDE:** Android Studio
* ⚙️ **Build System:** Gradle
* 🎨 **UI:** Android UI Components

## 🚀 Getting Started

### 📋 Prerequisites

Make sure you have the following installed:

* 🧑‍💻 Android Studio
* 📦 Android SDK
* ☕ JDK
* 🔧 Git

---

## 📥 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/achintyajain1502/SmartBillReminder.git
```
### 2️⃣ Open the Project

* 🚀 Open **Android Studio**
* 📂 Click **Open**
* 📁 Select the `SmartBillReminder` project folder
* ⏳ Wait for **Gradle Sync** to complete
* 🔧 If prompted, allow Android Studio to install or update required dependencies

### 3️⃣ Run the Application

* 📱 Connect an Android device or start an **Android Emulator**
* ▶️ Click the **Run** button in Android Studio
* 📲 Select your connected device
* 🎉 The application will be installed and launched

## 🏗️ Build the Project

To build the project using Gradle:

```bash
./gradlew build
```

For Windows:

```bash
gradlew.bat build
```
## 📦 Generate APK

To generate a debug APK on Windows:

```bash
gradlew.bat assembleDebug
```

The generated APK can be found at:
```bash
app/build/outputs/apk/debug/
```


## 🧪 Testing
Run the tests using:

```bash
gradlew.bat test
```
